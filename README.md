Lista de Tarefas — Tkinter + SQLite

Aplicação desktop simples para gerenciar tarefas, feita em Python com interface gráfica (Tkinter) e persistência de dados em banco SQLite.

Funcionalidades
Adicionar tarefas
Marcar tarefa como concluída / reabrir (duplo-clique na tarefa ou botão)
Remover tarefas
Dados salvos automaticamente em um banco SQLite local (tasks.db) — as tarefas continuam lá mesmo depois de fechar o programa
Tecnologias
Python 3
Tkinter (interface gráfica — biblioteca padrão do Python)
SQLite3 (banco de dados — biblioteca padrão do Python)

Nenhuma dependência externa é necessária.
